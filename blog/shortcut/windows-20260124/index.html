📌 快速記憶法:按「邏輯分類」記憶

1. Win 鍵 = 系統級操作

把 Win 鍵想成「我要控制整個 Windows 系統」:

  • Win + D → D = Desktop(桌面)
  • Win + E → E = Explorer(檔案總管)
  • Win + L → L = Lock(鎖定)
  • Win + S → S = Search(搜尋)
  • Win + I → I = Information/Settings(設定)
  • Win + R → R = Run(執行)

2. Ctrl 鍵 = 文件/內容操作

Ctrl 是「控制內容」的核心:

  • Ctrl + C/X/V → Copy/Cut/Paste(複製/剪下/貼上)
  • Ctrl + Z/Y → 向後/向前(復原/重做)
  • Ctrl + S → Save(儲存)
  • Ctrl + F → Find(尋找)
  • Ctrl + A → All(全選)

3. Alt 鍵 = 應用程式/視窗操作

Alt 是「切換應用層面」:

  • Alt + Tab → 切換應用程式
  • Alt + F4 → 關閉視窗
  • Alt + Space → 視窗選單

4. Shift 鍵 = 強化/反向操作

Shift 加上其他鍵通常是「加強版」:

  • Shift + Delete → 永久刪除(比普通 Delete 更強)
  • Ctrl + Shift + T → 重開分頁(比 Ctrl + T 更進階)
  • Win + Shift + S → 進階截圖

🎯 學習建議

第一週:每天必用(5個)

專注練這 5 個,直到成為肌肉記憶:

  1. Win + E - 開檔案總管
  2. Win + D - 顯示桌面
  3. Alt + Tab - 切換視窗
  4. Win + L - 鎖定(離開座位時)
  5. Win + Shift + S - 截圖

第二週:視窗管理(4個)

  1. Win + ← / → - 分割視窗(超實用!)
  2. Win + ↑ / ↓ - 最大化/最小化
  3. Alt + F4 - 關閉視窗
  4. Win + Tab - 虛擬桌面

記憶口訣

「DESLR」開頭最重要:

  • Desktop - 桌面
  • Explorer - 檔案
  • Search - 搜尋
  • Lock - 鎖定
  • Run - 執行

🖱️ 滑鼠操作快捷方式

基本組合

  • Ctrl + 拖曳 = 複製檔案
  • Shift + 拖曳 = 強制移動
  • Alt + 拖曳 = 建立捷徑
  • Ctrl + 滾輪 = 縮放(通用)

視窗拖曳

  • 往上丟 = 變最大(丟向天空)
  • 往左右丟 = 靠邊站(丟到牆邊)
  • 左右搖 = 其他視窗都閃開(搖晃清場)

瀏覽器

  • Ctrl + 左鍵 - 在新分頁開啟連結
  • 中鍵點擊連結 - 在新分頁開啟
  • 中鍵點擊分頁 - 關閉分頁

💡 終極秘訣

  1. 一次只記 3-5 個,不要貪心
  2. 強迫自己不用滑鼠完成某個任務
  3. 在便利貼寫下來,貼在螢幕旁邊
  4. 教別人就記得最牢(費曼學習法)
  5. 持續 21 天,讓它變成習慣

記住:不是要背所有快捷鍵,而是找出「你最常用的 10-15 個」,把它們練到不用想就能按出來。其他的需要時再查就好!
