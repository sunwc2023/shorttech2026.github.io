JWT 核心概念

  • Header: 描述 Token 類型和演算法
  • Payload: 存放使用者資訊和聲明
  • Signature: 確保 Token 完整性和真實性

Spring Security 整合要點

  1. 配置 oauth2-resource-server 依賴
  2. 設定 JWT 解碼器 (JwtDecoder)
  3. 配置 Security Filter Chain
  4. 實作 Token 驗證邏輯
  5. 處理權限和角色

最佳實踐建議

  • ✅ 使用強加密演算法 (RS256/ES256)
  • ✅ 設定合理的過期時間
  • ✅ 實作 Refresh Token 機制
  • ✅ 妥善保管私鑰
  • ✅ 驗證所有必要的聲明 (iss, aud, exp)
  • ⚠️ 避免在 Payload 存放敏感資訊
  • ⚠️ 注意 Token 大小限制
